# iatools-front

Panel de monitoreo del orquestador IA (GitHub Pages).

## Demo

`https://jeff-aporta.github.io/iatools-front/`

## Local

Servir la carpeta raíz (Live Server, `npx serve .`, etc.).

## Auth

Login vía **system-login** (`system-login:session` en sessionStorage).

Toggle **API local/online** apunta a `localhost:8787` o `iatools.jeffaporta.workers.dev`.

## Deploy

Repo público `iatools-front` — GitHub Pages desde rama `main`, carpeta raíz.  
Incluir `.nojekyll` en la raíz.
